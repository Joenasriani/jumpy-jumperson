# Jumpy Jumperson

**Status:** original browser arcade runner  
**Play:** https://joenasriani.github.io/jumpy-jumperson/  
**Creator:** Joe Nasr  
**Creator identity:** https://joe-nasr-signals.vercel.app/v2/

Jumpy Jumperson is a neon browser runner built around jumping, mid-air boosts, shields, obstacle avoidance, score progression and increasing speed.

## Gameplay

- one-button jump focused control
- airborne second jump / boost
- progressively faster obstacle patterns
- score and level progression
- desktop and touch controls

## Technology

HTML5, JavaScript, browser rendering and Web Audio.
